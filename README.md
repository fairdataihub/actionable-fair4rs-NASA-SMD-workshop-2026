# Repository of the presentation material for the NASA SMD Mission Software Workshop 2026 (September 15-17, 2026)

## About

This repository contains the material and information associated with our talk at the [**2026 NASA Science Mission Directorate (SMD) Mission Software Workshop**](https://science.data.nasa.gov/features-events/mission-software-workshop-2026), held September 15-17, 2026 in Pasadena, CA (hosted at Caltech) and virtually. Bhavesh Patel will give a talked titled "**FAIR Principles for Research Software: From Principles to Practical Guidelines**", where he will provide an overview of the Actionable FAIR4RS Task Force's work in translating the FAIR4RS Principles into concrete, implementable guidelines for research software developers.
